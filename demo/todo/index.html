Adding LocalBusiness JSON-LD (name, phone, address, hours, review rating) would help Google show richer results — star ratings, hours, click-to-call — directly in search. No downside, purely additive.

No Open Graph / social share preview tags

Sharing the site link in a text, Facebook post, or Slack currently shows no preview image or custom description. Adding og:title, og:description, og:image would fix that.

Mobile visitors lose in-page navigation

Feature You

Below 900px, the header only shows the "Free estimate" button — the Services/Why us links disappear entirely with no menu to replace them (this matches the original site's own behavior, so it's a design call, not a mistake). Worth deciding whether to add a simple mobile menu back for usability.

Form status messages aren't announced to screen readers

Best practice Claude

The success/error message after submitting the estimate form updates visually but has no aria-live region, so screen reader users aren't told whether their submission worked.

"Service may include" numbered lists aren't announced as numbered

Best practice Claude

The step numbers in each service's checklist are drawn with CSS counter() on a <ul> with list-style:none — purely visual. Screen readers won't announce "item 1 of 6," etc.

Below-the-fold images aren't lazy-loaded

Best practice Claude

Only the before/after gallery images use loading="lazy". Service card and service-detail photos load eagerly even though they're well below the fold — adding loading="lazy" there would shave a bit off initial page weight.

Readability Claude
